Your models appear in the Copilot Chat model picker as soon as the extension is active.

If you do not see them, the list may simply be long — scroll down and look for the `name` you gave each entry in `yoke.customModels`. With no custom models configured, you get the built-in DeepSeek cloud models instead, which do need an API key.

If a model is missing entirely, open `Yoke: Show Logs` — an invalid `customModels` entry is skipped and the reason is logged there.
